# VOX-T · 음성 온디바이스 전술 AI

Korean Defense Tech Hackathon 2026 (D4D × EDTH SEOUL) · **T4-2 핸즈프리 음성 온디바이스 전술 AI (Voice-first Tactical AI)**

손과 눈이 바쁜 병사가 **누르고 말하기(PTT)** 한 번으로 보고하면, 외부망 없이 기기 안에서

1. 잡음 섞인 무전 음성을 인식하고 (Whisper, 기기 내)
2. 수량·방위·거리·고도·이동 방향·시각·호출부호를 뽑아 **표준 보고(SALUTE)** 로 정리하고
3. 핵심 수치를 무전식으로 **복창(read-back)** 해 확인받고 ("공사오", "일사삼이")
4. 확정된 보고를 **방위·거리 상황도**에 표시하고
5. 동맹군용 **영문 한 줄**과 저대역 링크용 **초소형 메시지**(`UAV|2|045|1500|100|SW|1432`)로 바꾸고
6. "드론 목격 시 보고 절차 알려줘" 같은 질문에는 **교범(SOP)** 에서 근거를 찾아 답합니다.

## 왜 이렇게 만들었나

- **오프라인 우선**: 모든 처리가 브라우저 안(WebGPU / WASM)에서 돌아갑니다. 모델은 처음 한 번 받아 기기에 저장하고, 이후 비행기 모드에서도 동작합니다.
- **수치는 지어내지 않는다**: 숫자 추출은 규칙 기반 파서가 맡습니다. 원문에 없는 값은 "미확인"으로 남고, LLM은 빈 칸 보완·번역·교범 요약만 하며 파서가 찾은 수치를 절대 덮어쓰지 않습니다.
- **무전 음질 대응**: 300–3400Hz 대역 제한·잡음 효과를 켠 채로 시연할 수 있고, 음성 인식이 자주 틀리는 표현("방위"→"방이", "공사오"→"공사어", "일이공"→"1위공")을 보정합니다.
- **정정 절차**: "두 대, 아니 정정, 세 대"처럼 말하면 정정 이후 값만 씁니다.
- **어디서나 같은 앱**: 노트북과 안드로이드폰 크롬에서 설치 없이 같은 앱이 돕니다.

## 이번 해커톤에서 새로 만든 것

해커톤 기간에 처음부터 새로 만들었습니다. 이전에 만든 실시간 번역 자막 앱(Live Subtitles)은 클라우드 모델을 쓰는 구조라 코드는 가져오지 않았고 아이디어만 이어받았습니다.

- 한국어 무전 보고 파서(고유어·한자어·자릿수 읽기 숫자, 정정, STT 오인식 보정)
- SALUTE 보고 / 복창 / 영문 / 버스트 메시지 생성
- 가상 SOP 지식베이스와 오프라인 한국어 검색
- 브라우저 온디바이스 STT·LLM 파이프라인, PTT·무전 음질 효과, 상황도 UI
- 합성 무전 샘플 8종

## 실행

```bash
npm install
npm run build
node serve.mjs 8098   # http://localhost:8098  (마이크는 localhost 또는 HTTPS에서만 동작)
npm test              # 파서·보고 양식·SOP 검색 테스트
```

처음 열면 "모델 불러오기"를 눌러 음성 인식 / LLM 모델을 받습니다. 이후 네트워크를 끊고 사용하세요.

## 데이터

공개·합성 데이터만 사용합니다. 무전 샘플은 TTS로 만든 가상 보고이고, SOP는 시연용으로 작성한 **가상 교범**(실제 교범 아님)입니다. 실제 부대·좌표·개인 정보는 들어 있지 않습니다.
